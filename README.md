# Перед вами семейное древо.

По средней линии семейное древо разделяется на несколько частей. Рамочками выделены портреты тех, относительно кого выстраивается данный фрагмент древа.

Можно нажать на любой портрет и перейти по ссылке в архив человека, где вы найдёте фотографии, биографию, письма и иные материалы, связанные с этим человеком.

Вы также можете перейти в общий архив всех материалов: https://disk.yandex.ru/d/VC78Cm84A-dW0w
